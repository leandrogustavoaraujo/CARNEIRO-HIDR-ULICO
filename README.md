# Projeto Água Sem Energia — protótipo fiel à OFF GRID

Abra `index.html` no navegador. A página usa a folha de estilos do ZIP OFF GRID, com a mesma fonte Inter, hierarquia, espaçamento, cartões, cores e efeitos principais. O conteúdo foi adaptado ao carneiro hidráulico com garrafa PET.

Esta é a etapa estrutural e de copy. O mockup da apostila, os quadrados do carrossel e as três aplicações são representações temporárias em HTML/CSS. A página já explica o caminho da água e o Plano Completo, mas as fotografias e os mockups finais serão inseridos depois.

A nova oferta tem dois planos. O cartão de oferta da referência foi repetido para mostrar Básico (R$9,90) e Completo (R$27,90), mantendo o tratamento visual. Os botões de compra levam aos respectivos checkouts da Wiapy.

Nenhum script de rastreamento, depoimento ou imagem de energia solar do site de referência foi copiado para esta entrega.
